# Lost Fleet 拡張：マップ外ランダムセットアップ仕様（ドラフト）

作成: 2026-07-22。出典: 公式ルールブック日本語PDF（基本版・Lost Fleet版、ユーザー提供）。
ソロ（オートマ）ルールはスコープ外。マップ（宙域・宙間・深宇宙タイルの配置）もこの仕様の対象外。

## 1. 基本版のランダムセットアップ（現行実装＝照合済み）

| 要素 | プール | 抽選 | 実装状態 |
| --- | --- | --- | --- |
| 基本技術タイル | 9種（各4枚） | 9種→9スロット（トラック6＋フリー3）に割当 | ✅ |
| 上級技術タイル | 15枚 | 6枚（各トラック1枚） | ✅ |
| ラウンドブースター | 10枚 | 人数+3枚 | ✅ |
| ラウンド得点 | 物理10枚（8種×1＋同盟5VP×2） | 6枚→R1..R6 | ✅ |
| 最終得点 | 6枚 | 2枚 | ✅ |
| 同盟タイル（惑星改造Lv5） | 6種（各3枚、グリーン人専用は除外） | 1種 | ✅ |

## 2. Lost Fleet が追加・変更するランダム要素（LFルールブック p2-6, 13-15）

### 2.1 既存プールへの混合（「通常通りに準備」）
- **ラウンドブースター +4枚** → プール14枚、抽選は人数+3のまま。
- **ラウンド得点 +3枚** → 物理13枚、6枚抽選のまま。
- **最終得点 +3枚** → 9枚、2枚抽選のまま。
- **上級技術 +6枚** → 21枚。トラック用6枚に加え、**得点ボード拡張部に1枚**を追加抽選（計7枚使用）。

### 2.2 混合しない新要素
- **新基本技術タイル 3種（各4枚）**: 基本ゲームの9種とは**混ぜない**。宇宙船ボード上の技術タイルスペース（**2人プレイ=2ヶ所／3・4人=3ヶ所**）に1種ずつランダム割当。2人プレイでは余った1種を箱へ。
- **アーティファクトトークン 13枚**: **プレイ人数と同数**をランダムに選び、トワイライト（宇宙船）上のスペースに表向きで配置。
- **金枠同盟タイル 8枚**: **4枚**（2人プレイは**3枚**）をランダムに選び、各宇宙船に1枚ずつランダム配置。
- **経済研究エリア調整タイル**: **ランダムな面**を表向き（レベル3・4の収入を差し替える両面タイル）。
- **得点ボード拡張部の面**: 2人=25VP面固定／3・4人=探査シャトル面。**2ゲーム目以降は任意でランダム選択可**（オプション扱いにする）。

### 2.3 その他セットアップに影響する事項
- 宇宙船は4隻。**2人プレイではリベリオンを除外**（金枠同盟の配布数・技術スペース数に影響）。
- **改訂版タイルへの差し替え**（内容のみ、枚数不変）: 「惑星の種類」シンボルを持つ基本技術1種（現TS2）・上級技術1枚（現AT15）・最終得点1枚（現FS03）は、新惑星種（小惑星・原始惑星）を含めて数える改訂版に置き換わる。ID・抽選構造は不変で、LFモード時の表記注記のみ。
- 「惑星の種類による得点」パワーアクションの基礎点が3→2に変更（セットアップ外、評価フェーズで考慮）。
- プレイ人数: LFの対人ルールは2〜4人（1人=オートマはスコープ外）。

## 3. データモデル設計

### 3.1 入力
```ts
type BuildSetupInput = {
  seed: string;
  playerCount?: number;        // base: 1..4 / lostFleet: 2..4 にクランプ
  mode?: "base" | "lostFleet"; // 省略時 "base"
};
```
- マップ検索の searchKey 互換ルールに倣い、**mode が "base" のときは結果・キーに新フィールドを含めない**（スプレッド構築）。既存スナップショット・ゴールデンは不変。

### 3.2 カタログ追加（`data.ts`）
```ts
boostersLF: SetupTile[5..]        // RB11..RB14（4枚）
roundScoringLF: RoundScoringTile[] // RS10..RS12（3枚）
advancedTechLF: SetupTile[]        // AT16..AT21（6枚）
standardTechLF: SetupTile[]        // TSL1..TSL3（3種）
finalScoringLF: SetupTile[]        // FS07..FS09（3枚）
federationsGold: SetupTile[]       // FEDG1..FEDG8（8枚）
artifacts: SetupTile[]             // ART01..ART13（13枚）
```

### 3.3 ビルダー（LFモード時のみ実行される追加ストリーム）
既存の各ストリーム（standardTech / advancedTech / boosters / roundScoring /
finalScoring / federationLv5）は**シャッフル対象のID配列がLFプール込みに変わる**
（混合要素）。LF専用の抽選は**新しい独立ストリーム**で行い、基本版の出力に影響しない:

| ストリーム名 | 内容 |
| --- | --- |
| `advancedTechExtension` | トラック6枚を除いた残り15枚から1枚（得点ボード拡張部用） |
| `shipTech` | 新基本技術3種→宇宙船スペースへの割当（2人時は2種のみ配置） |
| `artifacts` | 13枚から人数分 |
| `goldFederations` | 8枚から4枚（2人時3枚）→船へ割当 |
| `econTileFace` | 2面から1面 |
| `extensionFace` | オプション有効時のみ2面から1面（既定は人数固定面） |

注意: 混合プール（例: boosters 14枚）のシャッフルは**基本版と同じストリーム名**を
使うが ID 配列が異なるため、**LFモードのゴールデンは基本版と別に固定**する。
基本版ゴールデンは現状のまま変えない（modeを含めない入力で回帰を担保）。

### 3.4 結果（LFモード時の追加フィールド）
```ts
advancedTech: { byTrack, extension: string }
shipTech: Record<ShipId, string>       // 配置スペースを持つ船→新基本技術ID
artifacts: string[]                    // 人数分
goldFederations: Record<ShipId, string>
econTileFace: "A" | "B"
extensionFace?: "vp25" | "shuttle"     // オプション時のみ
ships: ShipId[]                        // 2人時は rebellion を除く
```
`ShipId = "twilight" | "eclipse" | "rebellion" | "tfmars"`（既存 scoutKey と同一語彙）。

### 3.5 UI
- `/setup` に「基本版／Lost Fleet」モード切替（人数セレクタの隣）。
- LF時のみ: 拡張部の上級技術1枚・宇宙船（技術3種／金枠同盟／アーティファクト）・経済調整面のセクションを追加表示。

### 3.6 テスト方針
- 基本版ゴールデン: 不変（modeなし入力）。
- LFゴールデン: 別seedで新規固定。
- 不変条件: 混合プールの枚数（14/13/9/21）、上級7枚が相互排他、shipTech 2人時2種・
  3人以上時3種、goldFederations が船数と一致、artifacts=人数、など。

## 4. 新タイルの内容（LFルールブック別表II〜VIIから抽出・テキスト↔タイル対応は未確定）

抽出済みテキスト（対応付けは画像照合が必要、⚠️=B方式確認待ち）:

- **新ブースター4枚** ⚠️: 収入は「1鉱石か3クレジットか2パワー」のいずれか＋
  ①パス時ガイアフォーマー×3VP（小惑星入植に使った駒は除く）
  ②パス時惑星種類×1VP ③パス時深宇宙宙域（最低1惑星入植）×2VP
  ④特別: トークンをガイアエリアに置かない「ガイア計画の開始」＋即ガイア変換
- **新ラウンド得点3枚** ✅内容: ①未入植の宙域/深宇宙で鉱山建設+3VP
  ②未入植の種類の惑星に鉱山建設+3VP ③研究所建設+4VP
- **新最終得点3枚** ✅内容: ①小惑星入植 最多 ②自分の首府⇔学院の到達距離 最長
  ③深宇宙宙域（最低1惑星入植）最多
- **新基本技術3種** ⚠️: ①即時ボーナス獲得（詳細要画像） ②即時: 小惑星に無料で鉱山建設
  ③上級で覆われない限り基本到達距離+1
- **新上級技術6枚** ⚠️: 判明分=「取得時: レベル3以上の研究エリア×3VP」
  「取得時: 指定研究エリアの到達レベル×3VP」「収入: パワー駒2個（エリアIII）」他、要画像照合
- **金枠同盟8枚** ⚠️: ①12VP（緑面あり） ②任意の技術タイル1枚 ③到達距離無限の鉱山建設
  ④3段階無料改造＋鉱山建設 ⑤2段階無料改造＋鉱山建設 他、要画像照合
- **アーティファクト13枚** ⚠️: ①7VP（小惑星入植1鉱山扱い） ②パス時小惑星×2VP 等、要画像照合
